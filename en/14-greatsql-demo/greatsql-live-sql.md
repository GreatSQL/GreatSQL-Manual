# GreatSQL Live SQL (Beta)

GreatSQL Live SQL is an online GreatSQL testing experience environment in standalone mode, where you can run various SQL commands while following the GreatSQL user manual.

::: danger Notes
1. Up to 40 users can test online at the same time.

2. The environment will be automatically re-initialized when an anomaly occurs.
:::
