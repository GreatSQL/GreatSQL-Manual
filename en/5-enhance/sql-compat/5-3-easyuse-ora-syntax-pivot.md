# Oracle Compatibility - Syntax - PIVOT
---

The `PIVOT` syntax can display a query in the form of a cross-tabulation. Compared with a general query, a cross-tabulation has more columns and fewer rows.

## 1. Syntax

```sql
SELECT ... 
  select_expr [, select_expr] ...
  ...
  [FROM table_references
      [PARTITION partition_list] [pivot_clause]]
  [WHERE where_condition]
  ...

pivot_clause:
  PIVOT
    ( aggregate_function ( expr ) [[AS] alias ]
        [, aggregate_function ( expr ) [[AS] alias ] ]...
      pivot_for_clause
      pivot_in_clause
    )

pivot_for_clause:
  FOR { column
      | ( column [, column]... )
      } 

pivot_in_clause:
  IN ({
        { expr | ( expr [, expr]... ) } [ [ AS] alias]
      }...
    )
```

## 2. Definition and Usage

1. The `pivot_clause` defines on which fields the query will aggregate data.
2. The `pivot_for_clause` defines which columns will be grouped and then cross-aggregated.
3. The `pivot_in_clause` is used to filter the values of the columns in the `pivot_for_clause`. Each value in the clause will be a separate column, and the expressions used in the clause can only be constant expressions.
4. The columns not used by the `pivot_for_clause` and `pivot_in_clause` will be used as fields for implicit grouping.
5. The `select_expr` can only use the fields used for implicit grouping and the columns generated by the cross-aggregation in the `pivot_in_clause`.
6. There can be multiple `aggregate_function`s, but only one `aggregate_function` is allowed without an alias, and the `aggregate_function` does not support the `GROUP_CONCAT()` and `WM_CONCAT()` functions.

## 3. Oracle Compatibility Notes

- `XML with ANY` and `XML with Subquery` syntax are not supported

```sql
greatsql> CREATE TABLE t1(a INT, b INT, c INT);
greatsql> CREATE TABLE t2(a INT, b INT, c INT);
greatsql> SELECT * FROM t1 PIVOT XML (SUM(c) FOR a IN(ANY));
ERROR 1064 (42000): You have an error in your SQL syntax; check the manual that corresponds to your MySQL server version for the right syntax to use near 'XML (SUM(c) FOR a IN(ANY))' at line 1

greatsql> SELECT * FROM t1 PIVOT XML (SUM(c) FOR a IN(SELECT a FROM t2));
ERROR 1064 (42000): You have an error in your SQL syntax; check the manual that corresponds to your MySQL server version for the right syntax to use near 'XML (SUM(c) FOR a IN(SELECT a FROM t2))' at line 1
```

- Tables in `table_references` with columns of the same name are not supported

```sql
-- To execute this example, you need to switch sql_mode = ORACLE first, otherwise a syntax error will be reported; other examples are not affected
greatsql> SET sql_mode = ORACLE;
greatsql> CREATE TABLE t1(a INT, b INT, c INT);
greatsql> CREATE TABLE t2(a INT, b INT, c INT);
greatsql> SELECT * FROM t1 JOIN t2 USING(a, c) PIVOT(SUM(c) FOR (a) IN(1, 2, 3, 4, 5 ,6)); 
ERROR 1060 (42S21): Duplicate column name 'b'
```
