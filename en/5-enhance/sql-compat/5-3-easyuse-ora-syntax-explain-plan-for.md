# Oracle Compatibility - Syntax - EXPLAIN PLAN FOR
---

```
EXPLAIN PLAN FOR
  [STATEMENT]
```

This syntax is provided only for Oracle syntax compatibility; its actual function is the same as the native EXPLAIN.

Difference from Oracle: the EXPLAIN result is displayed directly.
