# Contribute
---
GreatSQL is an open source community that relies entirely on the community to provide a friendly development and collaboration environment.

## Register a Gitee Account
The GreatSQL source code is hosted on Gitee: [https://gitee.com/GreatSQL](https://gitee.com/GreatSQL)

Please refer to [https://gitee.com/help/articles/4113](https://gitee.com/help/articles/4113) to register your Gitee account, and set your primary email at [https://gitee.com/profile/emails](https://gitee.com/profile/emails).

## Start Your Contribution
### Assign an Issue to Yourself
First, find the issue list of the GreatSQL community: [https://gitee.com/organizations/GreatSQL/issues](https://gitee.com/organizations/GreatSQL/issues). If you are willing to handle one of these issues, you can assign it to yourself. Simply enter /assign in the comment box, and the bot will assign the issue to you. Each issue may already have exchanges and discussions among participants; if you are interested, you can also share your opinions in the comment box to join the discussion.

### Submit an Issue
If you intend to report a bug or submit a feature request to the community, please file an issue in the corresponding repository of the GreatSQL community. You can also contribute your opinions or suggestions to the GreatSQL community by raising issues.

### Submit a Pull Request
If the amount of code in a single submission is large, it is recommended to break large changes into a series of logically smaller ones; submitting them in stages makes code review easier. If your Pull Request does not receive enough attention, you can send an email to greatsql@greatdb.com to let us know.

## Welcome to Contribute
The GreatSQL community welcomes everyone to participate and contribute. Our goal is to build an open and shared open source technology community that, with the collective efforts of all, makes GreatSQL the most popular open source database in China.
