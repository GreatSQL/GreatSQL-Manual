# GreatSQL Introduction
---

The GreatSQL database is a donation project under the OpenAtom Open Source Foundation, with dual certification of "Trusted Open Source Community + Trusted Open Source Project" from CAICT (China Academy of Information and Communications Technology).

The GreatSQL database is an **open source and free** database that can meet financial-grade application scenarios on commodity hardware. It features **High Availability**, **High Performance**, **High Compatibility**, and **High Security**, and can serve as an ideal drop-in replacement for MySQL or Percona Server for MySQL.

GreatSQL is committed to keeping open source open. GreatSQL is released under the [GPLv2 license](https://gitee.com/GreatSQL/GreatSQL/blob/master/LICENSE).

The GreatSQL database is operated and maintained under the leadership of the [GreatSQL Community](https://greatsql.cn). A [large number of community maintainers, enthusiasts, and users](https://greatsql.cn/docs/community/6-thanks.html) have participated, contributing in many aspects including submitting code, functional testing and verification, discovering bugs, and documentation improvements.

For the advantageous features of GreatSQL, see: [GreatSQL Advantageous Features](../1-docs-intro/1-3-greatsql-features.md).
